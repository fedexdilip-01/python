⚖️ Conditionals: if, elif, else
📌 WHAT — Decision making in code: if condition: , elif, else.
💡 WHY — Execute different logic based on user input, data, or state.
📍 WHERE — Input validation, menus, games, data filtering.
🔍 Basic example
score = 85
if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
else:
    grade = "C"
print(f"Grade: {grade}")   # Grade: B
✅ Nested conditionals & logical operators (and, or, not) also possible.
🔄 Loops: for & while
📌 WHAT — for iterates over sequences, while repeats while True.
💡 WHY — Automate repetitive tasks, process lists, handle user retries.
📍 WHERE — Data processing, simulations, game loops.
🔁 For loop example
for i in range(3):
    print(f"Attempt {i+1}")
♾️ While loop + break
count = 0
while count < 5:
    print(count)
    count += 1
    if count == 3: break   # stops early
⏸️ break · continue · pass
📌 WHAT — break exits loop, continue skips iteration, pass does nothing (placeholder).
💡 WHY — Fine-tune loop behavior, avoid errors in stubs.
📍 WHERE — Search algorithms, input sanitization, early exit. 
for num in range(6):
    if num == 0:
        continue     # skip 0
    if num == 4:
        break        # stop at 4
    print(num)       # 1,2,3

# pass as placeholder:
def future_function():
    pass
🎯 continue → jump to next iteration | break → terminate loop immediately.
📘 EXAMPLE 1 — Login System with Retry (while + if/else + break)
📌 WHAT — A program that asks for password with limited attempts.
💡 WHY — Shows while loop, conditionals, and break in a realistic security scenario.
📍 WHERE — Authentication gates, admin panels, rate limiting.
⚙️ HOW — Uses max 3 attempts, break on success, else block runs if exhausted. 
# Example 1: Secure Access (while + if/else)
correct_password = "py123"
max_attempts = 3
attempt = 0

while attempt < max_attempts:
    pwd = input("Enter password: ")
    if pwd == correct_password:
        print("✅ Access granted!")
        break
    else:
        attempt += 1
        left = max_attempts - attempt
        if left > 0:
            print(f"❌ Wrong! {left} attempts left.")
        else:
            print("🔒 Account locked.")
            break
💡 Click to simulate password prompt (correct: py123)
📘 EXAMPLE 2 — Sum of Even Numbers (for + continue)
📌 WHAT — Sums only even numbers from 1 to N using continue to skip odds.
💡 WHY — Demonstrates loop filtering, use of modulo, and accumulator pattern.
📍 WHERE — Data preprocessing, statistical calculations, game scoring.
⚙️ HOW — For loop from 1 to N, if odd → continue, else add to total. 
# Example 2: Even number summer (continue usage)
N = 10
total = 0
for num in range(1, N+1):
    if num % 2 != 0:   # odd
        continue
    total += num
print(f"Sum of evens 1..{N} = {total}")   # 2+4+6+8+10 = 30
