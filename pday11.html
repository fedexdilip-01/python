λ Lambda Functions
📌 WHAT — Anonymous inline functions: lambda x: x*2
💡 WHY — Short, single-expression functions without def. Perfect for map/filter.
📍 WHERE — Callbacks, sorting keys, functional transformations. 
# Regular function
def square(x): return x**2

# Lambda equivalent
square = lambda x: x**2

# Used directly
result = (lambda x, y: x + y)(5, 3)  # 8
✨ Common: sorted(list, key=lambda x: x[1])
🗺️ map() & filter()
📌 WHAT — map(func, iterable) applies function to all items.
filter(func, iterable) keeps items where func returns True.
💡 WHY — Functional, concise, lazy evaluation (returns iterators).
📍 WHERE — Data transformation, cleaning, extraction. 
nums = [1,2,3,4,5]
squared = list(map(lambda x: x**2, nums))
evens = list(filter(lambda x: x%2==0, nums))

print(squared)  # [1,4,9,16,25]
print(evens)    # [2,4]
📉 reduce() & Comprehensions
📌 WHAT — reduce(func, iterable) cumulatively applies function (from functools).
List/dict comprehensions: [expr for item in iterable if condition]
💡 WHY — reduce for aggregation; comprehensions are Pythonic and fast.
📍 WHERE — Summing, product, flattening, generating transformed collections. 
from functools import reduce

nums = [1,2,3,4]
product = reduce(lambda x,y: x*y, nums)  # 24

# List comprehension (more Pythonic)
squares = [x**2 for x in nums if x%2==0]  # [4,16]
📘 EXAMPLE 1 — Lambda + Map/Filter: Price Calculator
📌 WHAT — Apply discount to prices using map, filter expensive items.
💡 WHY — Real-world e-commerce: transform prices, filter by threshold.
📍 WHERE — Shopping carts, pricing engines, data pipelines.
⚙️ HOW — map(lambda p: p*0.9, prices) for 10% off, filter(lambda p: p > 50). 
from functools import reduce

prices = [25, 60, 45, 100, 30, 80]

# Apply 10% discount using map
discounted = list(map(lambda p: round(p * 0.9, 2), prices))

# Filter products above $50 after discount
premium = list(filter(lambda p: p > 50, discounted))

# Total using reduce
total = reduce(lambda a,b: a+b, discounted)

print(f"Discounted: {discounted}")
print(f"Premium (>$50): {premium}")
print(f"Total: ${total}")

📘 EXAMPLE 2 — List & Dict Comprehensions
📌 WHAT — Generate transformed lists/dicts concisely using comprehensions.
💡 WHY — More readable and faster than traditional loops.
📍 WHERE — Data preparation, feature engineering, filtering large datasets.
⚙️ HOW — [x**2 for x in range(10)], {k:v*2 for k,v in dict.items()}. 
# List comprehension: squares of evens
evens_squares = [x**2 for x in range(1,11) if x % 2 == 0]

# Dict comprehension: number -> square
square_dict = {x: x**2 for x in range(1,6)}

# Nested comprehension: flatten matrix
matrix = [[1,2,3], [4,5,6]]
flattened = [num for row in matrix for num in row]

print(f"Even squares: {evens_squares}")
print(f"Dict: {square_dict}")
print(f"Flattened: {flattened}")
