📊 Variables & Data Types
📌 WHAT — Variables store values. Types: int, float, str, bool.
💡 WHY — Manage data, calculations, and logic.
📍 WHERE — Every Python script, from math to AI.
📘 Type examples

📘 EXAMPLE 1 — Greeting + Age with type conversion
📌 WHAT — Personalized welcome + year-of-birth calculation.
💡 WHY — Demonstrates input(), int() conversion, f-string formatting.
📍 WHERE — User profiles, simple registration forms.
⚙️ HOW — Ask name & age, compute birth year approximation. 
# Example 1: Interactive user bio
name = input("Enter your name: ")
age = int(input("Enter your age: "))
current_year = 2026
birth_year = current_year - age

print(f"\n✨ Hello, {name}!")
print(f"You are {age} years old, so you were probably born around {birth_year}.")
print(f"Welcome to the Python journey 🚀")

# Example 2: Variables & types in action
product = "Laptop"        # str
price = 999.99            # float
stock = 45                # int
in_stock = stock > 0      # bool

print(f"📦 Product: {product}")
print(f"💰 Price: ${price}")
print(f"📊 Units left: {stock}")
print(f"✅ Available: {in_stock}")

# Simple discount logic
if in_stock:
    discount = 0.15
    final_price = price * (1 - discount)
    print(f"🎉 15% OFF → Final price: ${final_price:.2f}")
