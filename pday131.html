📡 requests & JSON APIs
📌 WHAT — requests.get(url) fetches data from APIs. .json() parses JSON response.
💡 WHY — Access live data: weather, currency, news, stock prices.
📍 WHERE — Web apps, data pipelines, bots, financial tools. 
import requests

response = requests.get("https://api.example.com/data")
data = response.json()
print(data["key"])
🕸️ BeautifulSoup – HTML Parsing
📌 WHAT — BeautifulSoup(html, 'html.parser') extracts data from HTML.
💡 WHY — Scrape websites without official APIs (quotes, products, articles).
📍 WHERE — Price monitoring, research, content aggregation. 
from bs4 import BeautifulSoup

soup = BeautifulSoup(html, 'html.parser')
quotes = soup.find_all('div', class_='quote')
for q in quotes:
    print(q.text)
⚙️ Error Handling & Best Practices
📌 WHAT — Try/except for network errors, status code checks, timeouts.
💡 WHY — Robust apps don't crash on failed requests.
📍 WHERE — Production systems, scheduled tasks. 
try:
    r = requests.get(url, timeout=5)
    r.raise_for_status()
    data = r.json()
except requests.exceptions.RequestException as e:
    print(f"Error: {e}")
📘 EXAMPLE 1 — JSONPlaceholder API (requests + JSON parsing)
📌 WHAT — Fetch sample posts from JSONPlaceholder (free fake API).
💡 WHY — Learn API workflow: GET request → JSON response → extract data.
📍 WHERE — Testing, prototyping, learning API integration.
⚙️ HOW — requests.get(), .json(), iterate through results. 
import requests

response = requests.get("https://jsonplaceholder.typicode.com/posts/1")
post = response.json()
print(f"Title: {post['title']}")

📘 EXAMPLE 2 — BeautifulSoup: Extract Quotes from HTML Simulation
📌 WHAT — Parse simulated HTML to extract famous quotes and authors.
💡 WHY — Understand scraping logic: find elements by class/tag.
📍 WHERE — Quote collectors, content parsers, data mining.
⚙️ HOW — Create HTML string, BeautifulSoup parses, .find_all(). 
from bs4 import BeautifulSoup

html = '''<div class="quote">
    <span class="text">The only limit is your mind.</span>
    <span class="author">Einstein</span>
</div>'''

soup = BeautifulSoup(html, 'html.parser')
quotes = soup.find_all('div', class_='quote')
