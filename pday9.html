📘 EXAMPLE 1 — Simple Log File Analyzer (File + Exception Handling)
📌 WHAT — Reads a server log file, counts error lines, handles missing file gracefully.
💡 WHY — Real-world debugging, automated monitoring, robust I/O.
📍 WHERE — DevOps scripts, application health checks.
⚙️ HOW — Uses try/except, .readlines(), string methods to filter "ERROR". 
def analyze_log(filename):
    try:
        with open(filename, 'r') as file:
            lines = file.readlines()
            error_count = sum(1 for line in lines if "ERROR" in line.upper())
            return f"Total lines: {len(lines)}, Errors: {error_count}"
    except FileNotFoundError:
        return f"❌ File '{filename}' not found."
    except Exception as e:
        return f"⚠️ Unexpected error: {e}"

# Simulated usage
print(analyze_log("sample.log"))
