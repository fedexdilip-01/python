🏗️ Classes, Objects, __init__, self
📌 WHAT — Class = blueprint, object = instance. __init__ = constructor, self = instance reference.
💡 WHY — Model real-world entities, bundle data & behavior.
📍 WHERE — Games, simulations, web apps, data models. 
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def bark(self):
        return f"{self.name} says Woof!"

my_dog = Dog("Rex", 3)
print(my_dog.bark())
🧬 Inheritance & Polymorphism
📌 WHAT — Inheritance: child class gets parent attributes/methods. Polymorphism: same method different behavior.
💡 WHY — Reusability, extensibility, cleaner code architecture.
📍 WHERE — UI components, game characters, payment processors. 
class Animal:
    def speak(self):
        pass

class Cat(Animal):
    def speak(self):
        return "Meow!"

class Dog(Animal):
    def speak(self):
        return "Woof!"

# Polymorphism in action
animals = [Cat(), Dog()]
for a in animals:
    print(a.speak())
🔒 Encapsulation & Magic Methods
📌 WHAT — Encapsulation: hide internal data using _protected or __private. Magic methods: __str__, __repr__, __len__, etc.
💡 WHY — Data protection, readable object representation.
📍 WHERE — APIs, libraries, secure data handling. 
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.__balance = balance  # private
    
    def __str__(self):
        return f"Account({self.owner}): ${self.__balance}"
    
    def get_balance(self):
        return self.__balance
📘 EXAMPLE 1 — Inheritance & Polymorphism: Shape Hierarchy
📌 WHAT — Base class Shape with area() method; Circle and Rectangle override it.
💡 WHY — Demonstrates code reuse and polymorphic behavior.
📍 WHERE — CAD software, game physics, geometry calculators.
⚙️ HOW — Inheritance + method overriding + polymorphism. 
import math

class Shape:
    def area(self):
        pass

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    def area(self):
        return math.pi * self.radius ** 2

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    def area(self):
        return self.width * self.height

shapes = [Circle(5), Rectangle(4, 6)]
for s in shapes:
    print(f"Area: {s.area():.2f}")

📘 EXAMPLE 2 — Magic Methods: __str__, __repr__, __add__
📌 WHAT — Customize object string representation and operator behavior.
💡 WHY — Make objects printable, debuggable, support arithmetic.
📍 WHERE — Custom data types, vector math, debugging.
⚙️ HOW — Implement __str__, __repr__, __add__. 
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __str__(self):
        return f"Vector({self.x}, {self.y})"
    
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"
    
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

v1 = Vector(2, 3)
v2 = Vector(4, 5)
v3 = v1 + v2
print(v3)  # Vector(6, 8)
