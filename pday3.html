📋 Lists & Tuples
📌 WHAT — Lists are mutable sequences [], tuples are immutable ().
💡 WHY — Store ordered collections, modify lists (append, remove), keep tuples for fixed data.
📍 WHERE — Task queues, coordinates, configuration data.
🔍 List operations
tasks = ["code", "debug", "test"]
tasks.append("deploy")
print(tasks[0])       # code
print(tasks[-1])      # deploy
sliced = tasks[1:3]   # ['debug','test']
🎯 Tuple (immutable)
point = (10, 20)
x, y = point   # unpacking
📖 Dictionaries & Sets
📌 WHAT — Dict: key-value pairs {}, Set: unique unordered elements.
💡 WHY — Fast lookups, avoid duplicates, represent real-world objects.
📍 WHERE — User profiles, caching, membership tests. 
user = {"name": "Alice", "age": 25}
user["city"] = "NYC"     # add key
print(user.get("name"))

unique_nums = {1, 2, 3, 3}  # {1,2,3}
if 2 in unique_nums: print("found")
⚡ Indexing, Slicing & Comprehensions
📌 WHAT — Access elements via index [start:stop:step]. List/dict/set comprehensions.
💡 WHY — Concise transformations, efficient filtering.
📍 WHERE — Data cleaning, generating sequences, mapping values. 
nums = [0,1,2,3,4,5]
evens = nums[::2]      # [0,2,4]
squares = [x**2 for x in range(5)]  # [0,1,4,9,16]

# dict comprehension
square_dict = {x: x**2 for x in range(3)}
✨ Comprehension = compact loops + expression
📘 EXAMPLE 1 — Student Gradebook (Dict + List + Comprehension)
📌 WHAT — Manage student scores using dictionary, compute average with list comprehension.
💡 WHY — Shows realistic data aggregation, key-value access, and filtering.
📍 WHERE — Grading systems, report generation, data analysis.
⚙️ HOW — Dictionary mapping names → scores list, compute average for each student. 
# Gradebook: dict of student -> list of scores
gradebook = {
    "Alice": [88, 92, 85],
    "Bob": [75, 80, 78],
    "Charlie": [95, 91, 94]
}
# Using comprehension to compute averages
averages = {name: sum(scores)/len(scores) for name, scores in gradebook.items()}
print(averages)

📘 EXAMPLE 2 — Unique Tags & Set Operations (Set + List)
📌 WHAT — Extract unique tags from multiple lists using sets and set operations.
💡 WHY — Eliminate duplicates, find common/unique elements.
📍 WHERE — Tag clouds, recommendation systems, data deduplication.
⚙️ HOW — Convert to sets, union/intersection, then back to sorted list. 
article1_tags = ["python", "data", "tutorial"]
article2_tags = ["python", "machine-learning", "coding"]
unique_tags = set(article1_tags) | set(article2_tags)  # union
common = set(article1_tags) & set(article2_tags)
print(f"All tags: {sorted(unique_tags)}")
print(f"Common: {common}")
