📘 EXAMPLE 1 — System Info Tool (os, sys, datetime)
📌 WHAT — Gather system information using os, sys, and datetime modules.
💡 WHY — Understand environment, cross-platform scripting, logging timestamps.
📍 WHERE — Diagnostic tools, build scripts, deployment checks.
⚙️ HOW — Combine os.getcwd(), sys.platform, datetime.now(). 
import os, sys, datetime

def system_report():
    return {
        "OS": sys.platform,
        "Python": sys.version.split()[0],
        "Working Dir": os.getcwd(),
        "Timestamp": datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    }

print(system_report())

📘 EXAMPLE 2 — Custom Module Simulation + random/math

💡 WHY — Demonstrate module creation, random number generation, and math functions.
📍 WHERE — Data analysis pipelines, game utilities, reusable math libraries.

# stats_tools.py (custom module)
import random, math

def roll_dice(sides=6):
    return random.randint(1, sides)

def circle_area(radius):
    return math.pi * radius ** 2

# main script
from stats_tools import roll_dice, circle_area
print(f"Dice: {roll_dice()}")
print(f"Area: {circle_area(5):.2f}")
