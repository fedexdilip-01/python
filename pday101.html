🔢 NumPy Arrays & Operations
📌 WHAT — NumPy provides N-dimensional arrays, vectorized math, broadcasting.
💡 WHY — Fast numerical computations, less loops, memory efficient.
📍 WHERE — Scientific computing, ML preprocessing, image processing. 
import numpy as np

arr = np.array([1,2,3,4,5])
print(arr * 2)        # [2,4,6,8,10]
print(arr.mean())     # 3.0
matrix = np.array([[1,2],[3,4]])
🐼 Pandas Series & DataFrame
📌 WHAT — Series = 1D labeled array, DataFrame = 2D table (like Excel).
💡 WHY — Data cleaning, transformation, aggregation made easy.
📍 WHERE — Data analysis, CSV/Excel handling, time series. 
import pandas as pd

df = pd.DataFrame({
    'Name': ['Alice', 'Bob'],
    'Score': [85, 92]
})
print(df.head())
print(df['Score'].mean())
📘 EXAMPLE 1 — NumPy Array Operations Demo
📌 WHAT — Create NumPy arrays, perform element-wise operations, aggregation.
💡 WHY — Show vectorized computation (faster than Python loops).
📍 WHERE — Mathematical modeling, signal processing, statistics.
⚙️ HOW — Use np.array(), arithmetic, .sum(), .mean(), broadcasting. 
import numpy as np

# Create array & operations
scores = np.array([78, 85, 92, 88, 76])
scores_plus_bonus = scores + 5
average = scores.mean()
print(f"Original: {scores}")
print(f"+5 bonus: {scores_plus_bonus}")
print(f"Average: {average:.1f}")

📘 EXAMPLE 2 — Pandas DataFrame from Dictionary
📌 WHAT — Create DataFrame, explore data, compute descriptive statistics.
💡 WHY — Understand tabular data structure, prepare for CSV analysis.
📍 WHERE — Data exploration, reporting, business analytics.
⚙️ HOW — pd.DataFrame(), .describe(), column selection. 
import pandas as pd

data = {
    'Student': ['Anna', 'Brian', 'Carla', 'David'],
    'Math': [88, 76, 95, 82],
    'Science': [91, 85, 93, 79],
    'English': [85, 88, 90, 84]
}
df = pd.DataFrame(data)
print(df.describe())
