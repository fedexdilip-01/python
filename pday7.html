📝 String Methods & Formatting
📌 WHAT — String methods: .upper(), .lower(), .strip(), .replace(), .split(), .join().
💡 WHY — Clean and transform text data, parse user input, format outputs.
📍 WHERE — Data cleaning, logging, formatters, text analysis.
✨ f-strings (Python 3.6+)
name = "Alice"
score = 95
print(f"Hello {name}, your score is {score}%")
⚙️ .format() method
print("Hello {}, your score is {}".format(name, score))
🎯 Useful methods: " hello ".strip() → "hello"
"python,java".split(",") → ['python','java']
⚙️ Defining Functions · return · Default Args
📌 WHAT — def func_name(params): , return value, default arguments: def greet(name="User").
💡 WHY — Reusability, modular code, reduce duplication, better organization.
📍 WHERE — Libraries, scripts, data pipelines, web apps. 
def multiply(a, b=2):
    """Multiply a by b (default 2)"""
    return a * b

print(multiply(5))   # 10
print(multiply(5, 3))  # 15
📌 Functions can return any type: int, str, list, bool, None.
🧩 Combining Strings & Functions
📌 WHAT — Use functions to encapsulate string logic (validation, formatting).
💡 WHY — Build clean text processors, reusable formatters.
📍 WHERE — Email templates, slug generation, data sanitization. 
def clean_name(name, default="Anonymous"):
    cleaned = name.strip().title()
    return cleaned if cleaned else default

print(clean_name("  john doe  "))  # John Doe
📘 EXAMPLE 1 — Email Formatter (string methods + function + default args)
📌 WHAT — Function that formats a user's full name into a professional email signature.
💡 WHY — Showcases string methods (strip, title), f-strings, default arguments.
📍 WHERE — Automated email systems, user profile generation.
⚙️ HOW — Takes name, optional role & company, returns formatted signature block. 
def email_signature(name, role="Developer", company="TechCorp"):
    clean_name = name.strip().title()
    return f"""
    📧 {clean_name}
    💼 {role} @ {company}
    📌 "Code with Python!"
    """

# Usage
print(email_signature("  john smith  "))
print(email_signature("alice wu", "Data Scientist", "AI Labs"))

📘 EXAMPLE 2 — String Analyzer: vowels, palindrome check (functions + methods)
📌 WHAT — Multi-function module that analyzes text: count vowels, check palindrome, reverse string.
💡 WHY — Demos reusability, string methods, return values, and chaining.
📍 WHERE — Text analysis tools, word games, data validation.
⚙️ HOW — Functions with string methods .lower(), .replace() and loops. 
def count_vowels(text):
    vowels = "aeiou"
    return sum(1 for ch in text.lower() if ch in vowels)

def is_palindrome(text):
    cleaned = text.replace(" ", "").lower()
    return cleaned == cleaned[::-1]

def analyze_text(text):
    return {
        "original": text,
        "vowels": count_vowels(text),
        "palindrome": is_palindrome(text),
        "reversed": text[::-1]
    }

# Test
result = analyze_text("A man a plan a canal panama")
print(result)
